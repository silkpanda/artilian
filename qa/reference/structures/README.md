# Structure references

Inspiration screenshots for Artilian structures. These are other people's builds, collected for mood, massing and palette ideas. Don't copy them block for block. Screenshots of our own structures generating in-game go in `qa/evidence/`.

| File | What it shows | Ideas worth taking |
|---|---|---|

| `witch-cottage-purple-roof.png` | A cottage with a purple roof in a spruce forest, with amethyst clusters and lavender around it | A witch or mage hut. A roof color that matches the Starlight palette. Vines and crystals growing on the walls. |
